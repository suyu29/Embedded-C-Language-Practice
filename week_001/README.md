## Q1：分析指针与地址

**你完成的文件：`q01.c`。** 把分析写在注释中，在 `main()` 中验证合法表达式。

分析这段代码：

```c
uint16_t adc[4] = {100u, 200u, 300u, 400u};
uint16_t *p = &adc[1];
uint16_t *end = adc + 4;
uint16_t copy = *p;
*p = 250u;
++p;
```

你需要回答：

1. `adc[1]`、`&adc[1]`、`p`、`&p`、`*p` 各是什么类型，表示值还是地址？说明 `++p` 前后区别。
2. 最后 `copy`、数组四个元素和 `*p` 各是什么值？为什么复制出来的 `copy` 会或不会跟着原变量改变？
3. `p - adc`、`end - adc` 各是什么值和类型？`p + 1` 偏移多少个元素、多少字节？
4. `adc + 4`、`*(adc + 4)`、`adc + 5`、`p[-1]`、`adc - 1`、`end == adc + 4` 哪些允许求值？解释原因。
5. 另有一个独立数组 `other`，为什么不能用 `p < other` 或 `p - other` 检查它与 `adc` 的位置关系？

自测要求：只运行合法表达式。不要执行非法解引用或越界指针运算来“验证”。地址用 `%p` 和 `(void *)` 打印；指针差值类型为 `ptrdiff_t`。概念答案需要人工审查，程序能编译不代表推导正确。

## Q2：通过输出指针读取模拟传感器

**你完成的文件：`q02.c`。** 实现：

```c
int read_sensor(uint8_t sensor_id, uint16_t *out_adc);
```

功能：ID 1、2、3 的模拟 ADC 值分别为 `0`、`2048`、`4095`。通过 `out_adc` 把值写回调用者，成功返回 `0`。

边界要求：`out_adc == NULL` 返回 `-1`；其他 ID 返回 `-2`，不改变输出变量。不能通过全局变量传结果，也不能返回局部变量的地址。

在 `main()` 中自己测试：

- 三个有效 ID，检查返回值和输出 ADC。
- ID 为 0、4、255，输出原先设为 123，失败后仍应为 123。
- NULL，以及非法 ID 与 NULL 同时出现；都应返回 `-1`。
- 输出变量放在三元素数组中间，确认两侧元素没有被改变。

最后在注释中解释：为什么传入 `&sample` 可以修改调用者的 `sample`？

## Q3：用指针填充 ADC 数组

**你完成的文件：`q03.c`。** 实现：

```c
int fill_adc_samples(uint16_t *dst, size_t count,
                     uint16_t start, uint16_t step);
```

功能：生成 `count` 个数，第 `i` 个数的数学值为 `start + i * step`，每个数必须在 0～4095。

边界要求：

- `count == 0` 返回 `0`，允许 NULL，忽略 start/step。
- 非空数量配 NULL 返回 `-1`。
- 任何生成值越界，返回 `-2`，整个数组一个元素也不能改变。
- 单元素时只使用 start；step 可以为 0。
- 调用者保证有 count 个可写元素。

限制：通过 `*p` 与指针推进写入，不用 `dst[i]` 写数据；中间计算不能回绕后误判为合法。

自己测试：`(start,step,count)=(100,25,4)` 应得到 `100,125,150,175`；零元素、单元素、step=0、恰好 4095、首值或末值越界；`(65535,1,2)` 不能因回绕而成功。失败前填入哨兵值，检查数组不变。

## Q4：用起始指针和尾后指针遍历

**你完成的文件：`q04.c`。** 实现：

```c
int sum_adc_range(const uint16_t *begin, const uint16_t *end,
                  uint32_t *out_sum);
```

功能：对 `[begin,end)` 求和，通过 out_sum 输出结果；不修改输入，不读取 end 指向的位置。这里元素允许为完整 uint16_t 范围。

边界要求：

- out_sum 为 NULL 返回 `-1`。
- begin/end 都为 NULL 表示空范围，成功写入 0；只有一个 NULL 返回 `-1`。
- 非 NULL 的两个端点必须由调用者保证属于同一数组或它的尾后位置。
- 相等端点是空范围；同数组内 begin 位于 end 后面返回 `-1`。
- 和超过 UINT32_MAX 返回 `-2`，输出不变。
- out_sum 应是独立可写对象，不与输入重叠。

自己测试：`{100,200,300,400}` 的完整范围和子范围；相等端点；尾后空范围；NULL 组合；同数组反向范围；输出 NULL。额外可在宿主机用静态数组测试累加溢出，避免把大数组放到 MCU 栈上。

不要把两个独立数组的指针拿来比较大小或相减。这违反本题调用前提，函数不承担检测任意指针合法性的任务。

## Q5：通过结构体指针填充传感器数据

**你完成的文件：`q05.c`。** 数据结构已经提供，你实现函数：

```c
typedef struct {
    uint8_t id;
    uint16_t adc;
    uint16_t millivolts;
    uint8_t status;
} SensorData;

int fill_sensor_data(SensorData *out, uint8_t id, uint16_t adc,
                     uint16_t millivolts, uint8_t status);
```

功能：用 `out->成员` 写入四个字段。合法范围为：id 1～3、adc 0～4095、millivolts 0～3300、status 0～3。millivolts 是传入的测量值，本题不用计算 ADC 换算。

边界要求：out 为 NULL 返回 `-1`；任一字段越界返回 `-2`，原结构体保持不变；成功返回 `0`。

自己测试：最小和最大有效值；每个字段单独越界；id=0；NULL。失败后检查原对象不变；成功时检查成员值，不假设结构体的大小或填充字节。

## Q6：在指定偏移写入大端 uint16_t

**你完成的文件：`q06.c`。** 实现：

```c
int write_be16_at(uint8_t *buffer, size_t length, size_t offset,
                  uint16_t value);
```

功能：在 offset 写高 8 位，在 offset+1 写低 8 位。例如 0x1234 写成 `12 34`。

边界要求：buffer 为 NULL 返回 `-1`；指定位置不足两字节返回 `-3`；成功只改变指定两个字节并返回 `0`。调用者保证缓冲区确有 length 字节。失败时缓冲区完全不变。

限制：使用字节指针写入，不能强转为 uint16_t 指针；容量判断不能因 offset+2 回绕而错误放行。

自己测试：0x0000、0x1234、0xFFFF；偏移 0、奇数偏移和最后恰好可写的位置；容量 0/1；offset 等于或大于 length；offset=SIZE_MAX；NULL。检查其他字节未改变。

## 挑战：把传感器数据编码为 7 字节报文

**你完成的文件：`challenge.c`。** 本文件也提供 SensorData 定义，可以独立编译。实现：

```c
int encode_sensor_frame(const SensorData *sensor, uint8_t *buffer,
                        size_t capacity, size_t *out_written);
```

报文固定为：

| 字节偏移 | 内容               |
| ---- | ---------------- |
| 0    | 固定帧头 0xAA        |
| 1    | id               |
| 2、3  | adc，高字节在前        |
| 4、5  | millivolts，高字节在前 |
| 6    | status           |

测试预期：`id=2, adc=2048, millivolts=1650, status=1` 应得到 `AA 02 08 00 06 72 01`。

要求：

- 三个指针参数任一为 NULL，返回 `-1`。
- 字段范围同 Q5，非法返回 `-2`。
- 字段有效但容量小于 7，返回 `-3`。
- 成功只写 7 字节，设置 `*out_written=7`，返回 `0`。
- 失败时缓冲区和 out_written 保持原状，源结构体始终不变。
- 调用者保证这三个对象有效、容量真实且彼此不重叠。
- 逐字段编码，不复制结构体原始内存，不依赖本机字节序。
- 在本文件实现所需逻辑；不链接 q05.c 或 q06.c，避免多个 main。

自己测试：标准示例、最小/最大合法字段、容量 7 和大于 7、容量 0～6、每类 NULL、各字段越界。非法字段与不足容量同时出现时返回 `-2`。检查前后哨兵、剩余字节、源对象和失败前后的输出长度。
